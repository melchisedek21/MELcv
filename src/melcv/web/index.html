Ton assistant de candidatures, 100 % local

Colle le texte (même très long, en toute langue). Tu peux aussi coller un lien sur sa propre ligne : MELcv ira lire la page.

Remplis-le une fois : coordonnées, formation, expériences, compétences, langues. MELcv n'utilisera que ces informations, sans rien inventer.

Plus le modèle est gros, meilleurs sont les textes (et plus c'est lent). Pour en ajouter : ollama pull nom-du-modèle, par exemple qwen2.5:14b ou mistral-small.

16384 convient aux offres volumineuses. Monte à 32768 si ton ordinateur le permet.

Dépose d'autres documents dans les dossiers modeles (canevas de lettre) et references (listes de qualités, verbes d'action…) : ils seront pris en compte au prochain lancement.
